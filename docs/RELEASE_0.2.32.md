# Brooklyn Map 0.2.32

- Fix "Authorization policy mismatch" when saving OLED brightness or Station
  blue hold. Both POST routes now participate in the existing administrator
  authorization policy, retaining session authentication and CSRF checks.
- Add a regression check that every POST form generated by the signed-in
  status page is registered as a protected mutation endpoint.
- Preserve the 20-second default blue hold, saved OLED dimmer, map brightness,
  hardware pins, startup behavior and OLED address handling from 0.2.31.

Validation: 149 administrator authentication checks and 439 LAN settings/page
checks pass. All four supported firmware targets are built before publication.
