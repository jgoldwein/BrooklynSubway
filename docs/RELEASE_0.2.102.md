# Brooklyn Subway 0.2.102

Advanced now has three dedicated cards, making everyday settings easier to find:

- **Firmware updates:** current firmware, automatic updates On/Off, the newest known available release, and an Open firmware updates button.
- **My station alerts:** alerts On/Off, all selected stations, and separate View alerts and Choose stations buttons.
- **Personalization:** a clear explanation and Edit personalization button for names, greetings, celebration details, extras and support contact.

These replace the corresponding small buttons in the general tools card. The status summaries refresh automatically and are visible before sign-in. Existing administrator protection still applies to settings changes. Existing saved settings and update preferences are preserved.

Validation: web rendering and page-capacity checks, enabled/disabled update and alert summaries, all/none station choices, live status JSON and existing sign-in routing checks; all four firmware build targets. Hardware appearance has not yet been confirmed by the user.
