Align your map artwork

This creates draft calibration points, not a manufacturing approval. The page works offline and sends nothing.

  1. Select an LED. The board preview highlights its physical position.
  2. Click that LED's intended station/route position on your source image. Use LED designators, not station names alone: shared stations may have several LEDs.
  3. Repeat for at least six anchors spread across the map's width and height. Use separate additional stations to review the result.
  4. Download the landmarks JSON and run the Python fit command.
